# Manual Operativo - Andina Market 360

1. Verificar el archivo de entrada relativo [data/ventas.csv](../data/ventas.csv).
2. Ejecutar `python src/resumen.py --json docs/data/resumen.json` desde la raiz.
3. Revisar resultados en `docs/index.html` mediante servidor local.

4. Verificar en http://localhost:8000 y detener con Ctrl+C.
