# Guia de Contribucion - Andina Market 360

- Crear una rama descriptiva desde main (`feature/*` o `fix/*`).
- Usar mensajes claros: `feat:`, `fix:`, `docs:`, `test:`.
- Ejecutar `python -m unittest discover -s tests -v` antes de confirmar.
- Prohibido enviar datos reales, contrasenas o tokens.
- Reportar errores abriendo un Issue reproducible con pasos y muestra ficticia.
