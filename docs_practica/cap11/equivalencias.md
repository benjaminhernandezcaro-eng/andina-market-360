# Equivalencia Interfaz Grafica vs Terminal

| Accion en GitHub Desktop / VS Code | Comando Git equivalente | Ventaja | Limitacion |
|---|---|---|---|
| Commit to main | git add + git commit -m | Visualizacion rapida | Oculta flags avanzados |
| Fetch origin | git fetch origin | Un clic sin fusionar | Menos detalle de refs |
| Pull origin | git pull origin main | Integracion rapida | Puede sorprender con merge |
| Push origin | git push origin main | Indicador visual | Igual requiere permisos |
