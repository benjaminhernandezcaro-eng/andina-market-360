# Observaciones de Repositorio Publico (github.com/cli/cli)

| Pestana | Funcion principal | Diferencia con Andina Market 360 |
|---|---|---|
| Code | Muestra archivos, ramas y README | Nuestro caso usa Python y CSV simple |
| Issues | Reportes y solicitudes abiertas | Usamos plantilla bug_report.md |
| Pull Requests | Revisiones antes de fusionar | Flujo guiado en ramas feature/* |
| Actions | Ejecucion automatica de flujos CI | Ejecutamos unittest en ci.yml |
| Settings | Configuracion y GitHub Pages | Solo visible para el propietario |
