# Simulacion de Caso para Git LFS

- Escenario: Catalogo hipotetico con fotos HD de productos (>50 MB cada una).
- Uso de Git LFS: Almacena punteros ligeros en Git y binarios en servidor LFS.
- Implicacion para equipo: Colaboradores deben instalar git-lfs para descargar binarios.
- Estado en este equipo: git-lfs/3.8.1 (GitHub; windows amd64; go 1.27.3; git a662a6db)
- Comprobacion: No se convirtio ningun archivo de Andina Market a LFS.
